# Imágenes de proyectos

Coloca aquí tus 4 imágenes (fotos o renders) con estos nombres exactos para que `index.html` las tome automáticamente:

| Archivo | Proyecto |
|---|---|
| `proyecto-1.jpg` | Optimización de Estructuras Aeronáuticas |
| `proyecto-2.jpg` | Diseño y Fabricación de Laminados Compuestos |
| `proyecto-3.jpg` | Prototipado y Validación de Ensambles |

Proporción recomendada: **16:10** (por ejemplo, 1600×1000 px) para que las tarjetas queden parejas.

Si prefieres otros nombres o formato (`.png`, `.webp`), solo actualiza el `src="images/..."` correspondiente en `index.html` — está marcado con un comentario arriba de cada placeholder.

Una vez que agregues una imagen aquí, puedes borrar este archivo si quieres, no es necesario para que el sitio funcione.
